# 🎮 Tic-Tac-Toe Game (C# · Windows Forms)

A two-player **Tic-Tac-Toe (X-O)** desktop game built with **C# and Windows Forms (.NET)**, with two selectable themes: a clean Classic dark board and a Pharaonic Egyptian theme with hieroglyphic styling.

**Timeline:** Sep 2026 · **Stack:** C# · .NET Windows Forms · GDI+

---

## ✨ Features

- 🕹️ **Two game themes** selected from the start menu
- 👥 **Two-player local mode** (Player 1 vs Player 2)
- ✅ **Automatic win detection** across all rows, columns and diagonals
- 🟡 **Winning line highlight** - green in Classic mode, gold in Pharaonic mode
- 🤝 **Draw detection** when the board fills with no winner
- 🔄 **Instant restart** to play again
- 🎨 **Custom board rendering** with `Graphics.DrawLine` - no default WinForms borders
- 🖼️ **Themed icons** for X, O and empty cells per theme

## 🛠️ Technologies

C# · .NET Windows Forms · GDI+ custom drawing
